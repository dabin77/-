# Content design portfolio

Existing React, TypeScript and Vite portfolio adapted for the KREAM content design internship.

## Development

- Install: `pnpm install --frozen-lockfile`
- Start: `pnpm dev`
- Validate: `pnpm test --run`, `pnpm lint`, `pnpm build`
- Vercel production follows the repository's `master` branch. Build output: `dist`.

## Editing

- Copy, skills and project evidence: `src/data/portfolio.ts`
- Project image links and case descriptions: `src/components/ProjectCard.tsx`
- Layout and responsive styles: `src/styles/global.css`

## Content boundaries

The owner permits their name and photo. Published content excludes personal contact information, email, visa information and grades. Do not restore the old PDF or removed evidence images without checking their contents.

KINGO SPOT uses demonstration crowding and recommendation data. Hand in Hand reached the international competition pre-finals. The included certificate documents the Korean preliminary selection. Starfield is a team proposal, not a realized sales result.

Restaurant marketing includes menu planning for customer age groups, banner planning, production and printing, and promotional flyer creation. At the owner's request, those images are not included.

The existing visual style is retained. Project evidence images open in a new tab for inspection.

Project order: KINGO SPOT, HAND IN HAND, BALLON DE PARIS, STARFIELD SUWON, school promotional video.

Ballon de Paris is a course brand strategy proposal. The school video was a first-year team final assignment that placed first, not a competition or official university commission. These two entries use text layouts until original media is provided.
