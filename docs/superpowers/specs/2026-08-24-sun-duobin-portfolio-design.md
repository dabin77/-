# SUN DUOBIN 통합 포트폴리오 디자인 사양

## 목적

한국 기업의 인턴·신입 채용 담당자가 손다빈의 다문화 배경, 서비스·콘텐츠 기획 역량, UX/UI 경험, 생성형 AI 활용 능력과 실행 경험을 한 링크에서 파악할 수 있는 반응형 포트폴리오 사이트를 만든다. 특정 회사에 종속되지 않는 통합 포트폴리오로 구성하고, 대표 프로젝트 링크는 KINGO SPOT과 스타필드 수원 팝업 클러스터 기획안 두 개만 전면에 노출한다.

## 핵심 포지셔닝

- 중국어 원어민

- 서비스·콘텐츠 기획, UX/UI·사용자 조사, 생성형 AI, 중국 시장 인사이트, 실행·협업을 함께 갖춘 인턴·신입 지원자

- 배경: 어두운 섹션은 실제 `#0C0C0C`, 밝은 섹션은 실제 `#FFFFFF`
- 대형 글자: 차가운 실버 블루 그라데이션 `#646973` → `#BBCCD7`
- 본문: 어두운 면에서 `#D7E2EA`, 밝은 면에서 `#0C0C0C`
- 강조: 마젠타·바이올렛 계열 한 종류만 제한적으로 사용
- 타이포그래피: 영문 대형 제목은 Kanit 계열의 두꺼운 콘덴스드 인상, 한국어는 Pretendard 또는 시스템 한국어 산세리프
- 컨테이너: 반복 카드 그리드가 아니라 오픈 레이아웃, 가는 구분선, 넓은 여백, 섹션 간 둥근 아크 전환
- 핵심 이미지: 크롬과 투명 유리 리본이 교차하는 3D 브리지. 한국·중국·사용자·AI 연결을 상징하며 가짜 인물 사진은 사용하지 않는다.

## 상호작용

- 내비게이션은 각 섹션으로 부드럽게 이동한다.
- Hero와 섹션 제목은 페이드·상승 애니메이션을 사용한다.
- 3D 브리지는 포인터 위치에 따라 매우 작게 이동하고 `prefers-reduced-motion`에서는 정지한다.
- About 본문은 스크롤에 따라 단어 또는 글자 단위로 명암이 드러난다.
- 강점·Profile·Experience 행은 순차적으로 등장한다.
- 프로젝트 카드 두 개는 데스크톱에서 스티키 스택 효과를 사용하고 모바일에서는 일반 세로 흐름으로 전환한다.
- 외부 프로젝트 링크는 새 탭에서 열고 `rel="noreferrer"`를 사용한다.

## 반응형·접근성

- 1440×900 데스크톱과 390×844 모바일을 우선 검증한다.
- 초대형 타이포그래피는 `clamp()`와 뷰포트 단위를 조합하되 화면 밖으로 잘리지 않는다.
- 48px 이상의 터치 영역, 명확한 키보드 포커스, 시맨틱 섹션과 제목 구조를 사용한다.
- 장식용 이미지는 빈 대체텍스트, 프로젝트 캡처는 의미 있는 한국어 대체텍스트를 사용한다.
- 모든 핵심 콘텐츠는 JavaScript나 애니메이션이 없어도 읽을 수 있어야 한다.

## 구현 구조

- React 18 + TypeScript + Vite
- Framer Motion은 동작이 필요한 컴포넌트에서 직접 import하고 과도한 전역 스크롤 상태를 피한다.
- 데이터와 뷰를 분리한다.
  - `src/data/portfolio.ts`: 공개 문구, 프로필, 프로젝트, 경험
  - `src/components/`: 내비게이션, 섹션 제목, 행, 프로젝트 카드, 연락 버튼
  - `src/sections/`: Hero, About, Profile, Projects, Experience, Contact
- 긴 페이지 렌더링에는 `content-visibility`를 사용하고, 스크롤 리스너가 필요하면 passive로 등록한다.

## 검증 기준

- Vitest + Testing Library로 실제 공개 문구, 프로젝트 외부 링크, 내비게이션과 접근성 동작을 테스트한다.
- `npm run test`, `npm run lint`, `npm run build`를 통과해야 한다.
- 인앱 브라우저에서 페이지 정체성, 빈 화면 여부, 프레임워크 오류 오버레이, 콘솔 오류, 내비게이션 상호작용을 확인한다.
- 디자인 기준 이미지와 실제 데스크톱·모바일 스크린샷을 직접 비교하고, 카피·레이아웃·타이포그래피·색상·이미지 처리·컨테이너 모델의 차이를 수정한다.
